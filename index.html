📊 Modul Interaktif Excel: Mengolah Data Nilai

💡 Konsep Dasar Pengolahan Data di Excel:
  • Setiap rumus di Microsoft Excel WAJIB diawali dengan tanda sama dengan (=). Jika tidak, Excel akan menganggapnya sebagai teks biasa.
  • Rentang Sel (Range): Menggunakan tanda titik dua (:) untuk menghubungkan sel awal hingga sel akhir. Contoh: C1:G1 berarti mencakup sel C1, D1, E1, F1, dan G1.

📚 Rangkuman Fungsi Utama

1. SUM (Penjumlahan)

=SUM(sel_awal:sel_akhir)

Digunakan untuk menjumlahkan seluruh nilai angka dalam suatu rentang sel.

Contoh: =SUM(C1:G1) menjumlahkan semua nilai milik Andi.

2. AVERAGE (Rata-Rata)

=AVERAGE(sel_awal:sel_akhir)

Digunakan untuk menghitung nilai rata-rata aritmatika dari sekumpulan sel.

Contoh: =AVERAGE(C1:G1) menghitung rata-rata nilai Andi.

3. MAX (Nilai Tertinggi)

=MAX(sel_awal:sel_akhir)

Digunakan untuk mencari nilai angka terbesar dari rentang yang dipilih.

Contoh: =MAX(C1:C5) mencari nilai B.Indo paling tinggi.

4. MIN (Nilai Terendah)

=MIN(sel_awal:sel_akhir)

Digunakan untuk mencari nilai angka terkecil dari rentang yang dipilih.

Contoh: =MIN(C1:C5) mencari nilai B.Indo paling rendah.

🛠️ Cara Menggunakan Rumus pada Praktik

  1. Klik pada sel tempat hasil kalkulasi akan ditampilkan (misalnya sel H1 untuk Total Nilai Andi).
  2. Ketikkan rumus yang sesuai, contoh: =SUM(C1:G1).
  3. Tekan tombol Enter pada keyboard untuk mengeksekusi rumus.
